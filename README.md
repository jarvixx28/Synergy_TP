# # Synergy TaskPhase

## Overview

This repository contains my solutions for the **Synergy TaskPhase** conducted as part of the student project program. Each task focuses on developing practical programming, software engineering, Linux, Git, Python, statistics, and data analysis skills through hands-on assignments.

The repository is organized task-wise, with each task containing its own source code, documentation, reports, and supporting files.
