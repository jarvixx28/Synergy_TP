# Task 7 – Data Understanding and Measurement Basics

## Objective

The objective of this task was to understand the fundamental concepts of data before performing statistical analysis or machine learning. The report explains observations, variables, data types, measurement units, summary statistics, and the importance of domain knowledge while interpreting datasets.

---

## Topics Covered

- Observations and Variables
- Categorical and Numerical Data
- Raw Data and Processed Data
- Measurement Units
- Mean, Median, Minimum, Maximum and Range
- Importance of Domain Context
- Data Interpretation
